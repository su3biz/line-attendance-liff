LINE本人認証 試験ページ

準備完了。本人認証はボタンを押すまで開始されません。

ボタンを押すとLIFFを初期化します。ログインが必要な場合はLINEログインへ進みます。ログイン後、もう一度ボタンを押すと送信前の確認を表示します。

送信とデータの扱い

  • ID tokenの送信先は確認済みの隔離GASに固定しています。送信先の入力欄はありません。
  • 確認後に限り、tokenをPOST本文の id_token として一度送信します。
  • tokenやユーザー情報を画面、URL、console、ブラウザー保存領域、明示ログに記録しません。
  • Apps Scriptの実行履歴などGoogle側の自動記録にPOST本文が残るかは未確認です。
  • このページは noindex 指定ですが、公開URLを知る人はアクセスできます。

本人認証テスト

ボタンを押しただけではID tokenは取得・送信しません。送信直前に、送信先と未確認事項を含む確認ダイアログを表示します。
